# 分享页沉浸浪漫与自由享受双模式实现

## 目标

- 在同一个公开分享链接中实现“沉浸浪漫”和“自由享受”双模式。
- 首次访问以完整礼物仪式为主，沿既有外围草地、入口、主路、小屋、照片墙、情书桌和花园中段完成约一分钟自动第一人称叙事。
- 情书阅读阶段暂停剧情，只有“珍藏这封信”才能继续；结尾原地交接第一人称控制，不重新加载或跳镜头。
- 保持现有实例化玫瑰与 LOD 性能边界，让玫瑰在镜头前方从含苞状态逐区开放，向日葵不受影响。

## 领域合同

本任务为 Hybrid（混合）领域，由 `garden-experience` 功能层负责集成。

| 子系统 | 领域 | 稳定所有者 | 输入 | 输出 | 关键约束 |
| --- | --- | --- | --- | --- | --- |
| `story.romantic-share` | Graphics / 时间信号 | `garden-experience` | 剧情时钟、暂停、珍藏事件 | 阶段、进度、花开波、天空命令、UI 状态 | 单一时钟、可确定性重放 |
| `route.romantic-camera` | Architecture / circulation | `RomanticCameraDirector` | 米制锚点、阶段进度、地面高度 | 相机位置和注视目标 | 第一人称眼高、不穿墙、不与手动控制并写 |
| `graphics.rose-bloom-wave` | Graphics | `CottageGardenPlanting` | 开放波信号、实例根位置 | 含苞到盛放的 GPU 形变 | 实例化、LOD 不重置、向日葵不受影响 |
| `interaction.letter-keepsake` | UI / state | `LoveLetterReader` 与剧情协调器 | 打开、关闭、珍藏 | 暂停或恢复剧情 | 关闭不等于珍藏 |
| `surface.shared-gift` | UI | 分享页体验层 | 接收者、赠送者、完成状态 | 封面、暂停/跳过、结束与自由入口 | 全画布、克制、不遮挡场景 |

## 质量合同

| 尺度 | 必须满足 | 阻断失败 |
| --- | --- | --- |
| Macro | 首次礼物入口、完整剧情、结尾原地解锁形成单一情绪弧线 | 自动镜头与自由控制冲突，或流程无法到达自由模式 |
| Meso | 铭牌、花开、照片、情书、夜色、流星按顺序由同一状态机驱动 | 任一剧情门禁依赖不可靠定时器或可被关闭情书提前绕过 |
| Micro | 花在视野前方约 `2.2–3.2m` 开始、星空短句停留至少 5 秒、状态可重放 | 花在身后弹开、LOD 后闭合、结束时跳镜头 |

## 坐标、时间与信号

- 世界单位为米，`+Y` 向上，入口位于 `+Z`，小屋位于主路 `-Z` 方向。
- 剧情时间单位为秒；情书、页面隐藏和用户暂停均冻结剧情时间。
- 固定剧情端点：`0 / 3 / 9 / 13 / 23 / 27 / 34 / 37 / 44 / 54 / 59 / 63s`。
- 剧情时钟是所有相机、花开、门户、天空和 UI 的唯一时间权威；不使用独立 `setTimeout` 链。
- 手动控制与自动镜头必须互斥；交接时以当前相机姿态初始化手动控制。

## 实际验收结果

- 自动段固定为 `63s`，情书阅读期间不累计；页面隐藏也冻结同一剧情时钟。
- Playwright 桌面流程已完整经过封面、自动路径、情书合上不推进、珍藏继续、流星终幕和原地自由交接；控制台 `0 errors / 0 warnings`。
- `390 × 844` 移动视口已检查封面排版、双模式入口和触屏自由模式提示。
- 本地未启动 PostgreSQL，因此分享路由的数据读取由构建与服务单元边界覆盖；浏览器验收使用同一个 `GardenExperience` 访客模式的临时 QA 构建，测试后已恢复首页原模式。
- 验收截图位于被 Git 忽略的 `output/playwright/`，仅作为本地视觉证据，不进入产品资源。

## 前端艺术约束

- 视觉论点：完整 Three.js 花园是唯一主视觉，礼物封面像一层薄雾与信纸，不引入卡片墙或多重面板。
- 内容计划：首次封面只保留赠送关系、一个主动作和一个弱化自由入口；剧情中除情书提示外不显示控制；结束只显示结束语和自由入口。
- 交互论点：封面柔和揭幕、玫瑰沿路径开放、结尾从系统导演无缝交接给接收者；所有效果响应减弱动画。

## 开放决策

- 背景音乐已有配置入口但没有确认可用的实际音频资产；音乐缺失时以现有环境音和静音可用为验收基线，不阻断视觉流程。
- WebGL 失败时错误边界直接呈现赠送关系、完整情书和结束语；照片静态画廊可在后续按实际低端设备覆盖率评估是否补充。
