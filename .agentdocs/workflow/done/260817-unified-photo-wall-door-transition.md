# 小屋整墙照片墙与双向门户切换

## 目标

- 删除室内右侧木格栅，恢复圆桌、书柜与门之间的连续视线和通道。
- 将东墙三张照片合并到北侧前墙，与原五张照片组成完整八联照片墙；整体上移并放大，减少墙面空白。
- 照片步骤改为按墙面位置选择插槽，用户点击哪个相框就为哪个位置上传或替换照片；未上传位置继续使用默认图片。
- 桌面三支蜡烛收敛为一支更大的暖白色柱蜡烛，放在桌面相框与花瓶之间。
- 访客跨入室内并离开门扇扫掠范围后自动关门；从室内按 `E` 重新开门，跨出后同样自动关门。
- 开门期间保持外部高密度花园可见，避免从室内看向门外时只剩稀疏地形。

## 视觉与空间依据

- 当前截图只约束小屋内部构图与门内视角，不复制截图中的红框或 UI 文案。
- 照片墙目标图为 `../../assets/photo-wall-target-v3.png`：八张照片沿同一中心线形成连续画廊，只使用横向 `3:2/4:3` 与竖向 `2:3/3:4` 常见照片比例，禁止全景条幅、拉伸和异常裁切。
- 北墙可用净宽约 7.52 米，照片墙控制在约 6.6 米内；最高点低于灯串，最低点高于墙裙压顶。
- 删除格栅只移除非承重装饰构件，不修改墙体、门洞、家具碰撞与主要漫游路线。

## 照片编辑体验

- 视觉论点：把暖木色墙面本身作为主要操作面，八个相框插槽直接复刻实际空间顺序，不再使用无方位含义的九宫格。
- 内容计划：前墙八联布局图负责位置选择，桌面相框作为独立第九插槽；每个位置显示当前照片或默认纪念图，并就地提供替换与恢复默认操作。
- 交互论点：悬停或聚焦时相框轻微提亮，已上传位置显示清晰状态点；选择文件后原位更新缩略图和 3D 预览，不改变其他位置。
- `photo-01` 至 `photo-09` 必须写入相框的显式位置参数，场景解析不得再依赖实例数组顺序猜测照片位置；旧配置缺少显式位置时仍按原有顺序兼容。

## 门户事务

- 开门时记录出发侧；只有确实跨过门槛抵达另一侧后才登记自动关门，避免刚按 `E` 就被自动关闭。
- 自动关门必须等待访客离开门扇扫掠体；视觉、碰撞和导航继续由同一 epoch 原子推进。
- 室外进入、室内出去采用同一套事务；中途折返不触发到达侧自动关门。
- 门扇打开时外景保持完整，关门后室内可卸载室外高密度花草。
